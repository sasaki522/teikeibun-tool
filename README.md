# 求職者対応 定型文作成ツール

キャリアアドバイザーが求職者へLINEで送る文面を、シーン別にワンクリックで作成できる静的Webツールです。

## まず使いたい方へ

### Google Chromeで開くURL

GitHub Pagesを有効化すると、普通のGoogle Chromeで以下のようなURLを開くだけで使えます。

```text
https://sasaki522.github.io/teikeibun-tool/
```

今回の公開URLは以下です。

```text
https://sasaki522.github.io/teikeibun-tool/
```

> Google Chromeの検索欄ではなく、画面上部のアドレスバーに貼り付けて開いてください。

### 公開URLを書いておく欄

GitHub Pagesを有効化したら、表示されたURLをここにメモしておくと便利です。

```text
公開URL：https://sasaki522.github.io/teikeibun-tool/
```

## このツールでできること

- 求職者名を入力すると、文面内に自動で「様」付きで反映します。
- 求職者名が未入力の場合は「求職者様」として生成します。
- 企業名を入力すると、各シーンに合わせて自然に反映します。
- 企業名が未入力でも違和感のない文面を生成します。
- 面接日時、提出物、担当者名、電話番号、注意点などを補足情報として追記できます。
- 補足情報に `面接日時：本日 14:00` のように書くと、面接前フォローやリマインド文面に「本日、14時から」の形で自然に反映します。
- 文面はLINEで送りやすいよう、寄り添い感があり、前向きなびっくりマーク多めのトーンにしています。
- 35種類のシーン別ボタンでLINE文面をすぐに生成できます。
- 各シーンで「柔らかめ」「標準」「クロージング強め」の3トーンを選べます。
- 35シーン × 3トーンの合計105パターンを、シーンごとの目的に合わせた専用テンプレートとして用意しています。
- 生成文面をワンクリックでコピーできます。
- 入力内容と生成文面をまとめて消せるリセット機能があります。
- HTML / CSS / JavaScript のみで動作します。
- スマホでも使いやすいレスポンシブ対応です。
- GitHub Pagesでそのまま公開できます。

## どのファイルに何があるか

| ファイル名 | 内容 | 初心者向け説明 |
| --- | --- | --- |
| `index.html` | 画面の骨組み | ブラウザで開くメインファイルです。入力欄やボタンがあります。 |
| `style.css` | デザイン | 色、余白、スマホ表示、ボタンの見た目を調整しています。 |
| `script.js` | 動き・定型文 | ボタンを押したときに文面を作る処理、コピー、リセットがあります。 |
| `README.md` | 説明書 | このファイルです。使い方と公開手順を書いています。 |

## ローカルで試す方法

まだGitHub Pagesで公開していない場合でも、自分のパソコンで動作確認できます。

1. このリポジトリをダウンロードまたはクローンします。
2. フォルダの中にある `index.html` を探します。
3. `index.html` をダブルクリックします。
4. Google Chromeなどのブラウザでツールが開きます。
5. 求職者名、企業名、補足情報を必要に応じて入力します。
6. 「柔らかめ」「標準」「クロージング強め」からトーンを選びます。
7. 使いたいシーンのボタンを押します。
8. 生成された文面を確認し、「コピー」ボタンでコピーしてLINEに貼り付けます。

静的サイトのため、サーバーを起動しなくても `index.html` を直接開くだけで利用できます。

## GitHub Pagesで公開する手順

この手順を行うと、URLを1つ共有するだけで誰でもGoogle Chromeなどのブラウザから使えるようになります。

### 1. GitHubにファイルを置く

このリポジトリに以下の4ファイルがあることを確認して、GitHubへpushします。

- `index.html`
- `style.css`
- `script.js`
- `README.md`

### 2. GitHub Pagesを有効化する

1. GitHubで `teikeibun-tool` リポジトリを開きます。
2. 画面上部、または右上付近にある `Settings` をクリックします。
3. 左メニューの `Pages` をクリックします。
4. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
5. `Branch` で公開したいブランチを選びます。通常は `main` です。
6. フォルダは `/ (root)` を選びます。
7. `Save` をクリックします。

### 3. 公開URLを確認する

GitHub Pagesを有効化してから数分待つと、`Pages` 画面に公開URLが表示されます。

公開URLは通常、以下の形になります。

```text
https://sasaki522.github.io/teikeibun-tool/
```

表示されたURLをGoogle Chromeで開くと、このツールを使えます。
URLはGoogle検索欄ではなく、ブラウザ上部のアドレスバーに貼り付けて開いてください。
そのURLをLINEやメールで共有すれば、URLを知っている人も同じツールを使えます。

## シーン一覧

### 初回対応

- 登録直後
- ヒアリング日程調整
- 面談前日
- 面談後フォロー

### 応募

- 求人提案
- 応募意思確認
- 推薦完了
- 書類選考中
- 書類通過
- 結果遅延フォロー

### 面接

- 面接日程調整
- 面接確定
- 面接3日前
- 面接前日
- 面接当日朝
- 面接30分前
- 面接直後
- 面接結果待ち
- 最終面接前
- 最終面接後

### 内定

- 内定速報
- 内定詳細説明

### 入社

- 入社書類提出
- 入社日確定
- 入社1週間前
- 入社前日
- 入社当日
- 入社1週間後
- 入社1ヶ月後

### 掘り起こし

- 音信不通掘り起こし
- モチベーションアップ
- お祝い連絡

## トーンの使い分け

- `柔らかめ`：不安が強い方や、久しぶりの連絡にも使いやすい寄り添い文面です。
- `標準`：通常の連絡で使いやすい、丁寧かつ前向きな文面です。
- `クロージング強め`：応募率向上、面接参加率向上、内定承諾率向上、入社率向上を意識し、次の行動を促したい場面向けです。

## 注意事項

- このツールはブラウザ上だけで動作し、入力内容を外部に送信しません。
- 生成文面は定型文のため、送信前に求職者の状況に合わせて必要に応じて調整してください。
- 実際の公開URLは、GitHub Pagesを有効化したGitHubアカウント名によって変わります。
